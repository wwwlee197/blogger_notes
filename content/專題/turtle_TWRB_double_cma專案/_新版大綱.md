
### 1. `multi_cam_main.py` - 程式入口

唯一的程式入口

- **功能概要**: 作為一個 ROS 2 節點，管理所有硬體（雙攝影機），處理所有底層的視覺運算，將指令分派給自走車控制器。
    
- **核心功能**:
    
    1. **設定模式 (Setup Mode)**: 這是程式啟動後的第一個階段。它提供了一個互動介面，讓您可以：
        
        - 預覽雙鏡頭的畫面。
            
        - 透過畫面重疊處的aruco按下`空白鍵`，自動計算出攝影機之間的**空間轉換關係 (單應性矩陣 H)**。
            
        - 用滑鼠點擊畫面來**測試並驗證**共享座標系統是否準確。
            
        - 直到您按下`Enter`確認設定無誤，程式才會進入下一步。
            
    2. **雙鏡頭管理**: 它會同時開啟並讀取兩台攝影機的影像。
        
    3. **建立統一標記字典 (`unified_markers`)**: 這是此檔案最關鍵的功能。在每一幀，它會：
        
        - 分別偵測兩個畫面中的 ArUco 標記。
            
        - 將所有偵測到的標記，無論來源是哪個攝影機，全數轉換到**以攝影機1的畫面為基準的「共享座標系」**中。
            
        - 最終產出一個字典，其中包含每個可見標記的 ID、在共享座標系中的**2D像素座標**、**2D角點資訊**以及它來自哪個攝影機。
            
    4. **分派任務**: 它會將這個包含完整環境資訊的 `unified_markers` 字典，同時傳遞給 `ID1` 和 `ID2` 的控制器進行決策。
        
- **資料流程**:
    
    - **輸入**: 來自兩台攝影機的原始影像幀、使用者的鍵盤與滑鼠操作。
        
    - **輸出**: `unified_markers` 字典，分發給 `ID1.py` 和 `ID2.py`。

### 2. `ID1.py` (`ArucoPIDController2D`) - 領導者控制器

這個檔案負責控制**機器人1 (領導者)** 的所有行為。

- **角色定位**: 一個專注於**2D像素平面**的 PID 控制器，目標是將機器人1移動到共享座標系中的一個**靜態目標點**。
    
- **核心功能**:
    
    1. **完全2D化控制**: 摒棄了原有的 3D 空間姿態估算 (`estimatePoseSingleMarkers`)。所有的計算，包括距離和角度，都在 `multi_cam_main.py` 提供的 2D 共享像素平面上進行。
        
    2. **接收目標**: 在「設定模式」結束後，它會讓使用者輸入一個目標像素座標（例如 `(400, 240)`）。
        
    3. **狀態感知**: 它從 `unified_markers` 字典中，根據自己的 ID (`robot_id = 1`) 找到自己當前的像素座標和角點資訊。
        
    4. **2D姿態估算**: 它透過一個輔助函式 `_estimate_orientation_2d`，直接從 Marker 的四個角點在 2D 畫面上的透視形狀，計算出機器人當前的平面朝向角度。
        
    5. **PID運算**: 根據當前位置與目標點的**像素距離誤差**和**角度誤差**，透過 PID 演算法計算出前進的線速度和旋轉的角速度。
        
    6. **發布指令**: 將計算出的速度封裝成標準的 ROS 2 `Twist` 訊息，發布到 `/cmd_vel` 主題。
        
- **資料流程**:
    
    - **輸入**: 從 `multi_cam_main.py` 傳來的 `unified_markers` 字典。
        
    - **輸出**: 發布到 `/cmd_vel` 的 `Twist` 速度指令。

### 3. `ID2.py` (`ArucoPWMController2D`) - 追隨者控制器

這個檔案負責控制**機器人2 (追隨者)** 的所有行為。

- **角色定位**: 一個同樣在**2D像素平面**上運作的 PID 控制器，目標是**動態追蹤**並跟隨機器人1。
    
- **核心功能**:
    
    1. **完全2D化控制**: 與 `ID1.py` 一樣，所有邏輯都在 2D 像素平面上運作。
        
    2. **動態目標鎖定**: 它會同時在 `unified_markers` 字典中尋找自己 (ID=2) 和目標 (ID=1) 的資訊。
        
    3. **追隨點計算**: 它的目標點不是機器人1的中心，而是一個動態計算出的、位於機器人1**後方固定像素距離**（例如 120 像素）的虛擬點。這個點會隨著機器人1的移動和轉向而即時變化。
        
    4. **雙階段控制**: 為了讓追隨行為更流暢，它採用了兩段式邏輯：
        
        - **距離較遠時**: 優先朝向追隨點移動，縮小距離。
            
        - **距離較近時**: 優先調整自身姿態，與機器人1的朝向對齊。
            
    5. **PID運算與輸出**: 根據計算出的像素距離和角度誤差，透過 PID 演算法直接算出左右輪需要的**PWM馬達控制值**。
        
    6. **發布指令**: 將計算出的 `[左輪PWM, 右輪PWM]` 封裝成 `Int16MultiArray` 訊息，發布到 `/set_pwm` 主題。
        
- **資料流程**:
    
    - **輸入**: 從 `multi_cam_main.py` 傳來的 `unified_markers` 字典。
        
    - **輸出**: 發布到 `/set_pwm` 的 `Int16MultiArray` PWM指令。
